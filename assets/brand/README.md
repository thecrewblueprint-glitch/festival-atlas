# Production Atlas brand image package

This folder contains website-ready image assets for Production Atlas.

## Files

- `production-atlas-mark.svg` — square brand mark for cards, app references, small page sections, and profile-style placements.
- `production-atlas-logo-lockup.svg` — horizontal logo / wordmark lockup for header, footer, landing sections, and documentation.

## Additional package locations

- `../web/production-atlas-hero-banner.svg` — wide hero/banner image for homepage or marketing sections.
- `../social/production-atlas-og-1200x630.svg` — editable social preview source art.
- `../social/production-atlas-og-400x400.jpg` — compact repository-hosted Open Graph preview image currently used by `index.html`.
- `../icons/favicon.ico` — browser favicon package.

## Usage rule

These are public-safe brand assets only. They do not contain private contacts, private field notes, pay rates, lodging information, or source links.
